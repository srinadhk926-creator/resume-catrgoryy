Practical 1: Flask ML System

Modular Flask application with scikit-learn Pipeline serialization (TF-IDF + Logistic Regression), input validation, SQLAlchemy persistence, and unit tests.

🐳

Practical 2: Docker Container

Containerized with multi-stage Python 3.11-slim base image, non-root user permissions, Gunicorn WSGI server on port 5000, and isolated environments.

Deployed on an Ubuntu EC2 instance with custom Security Groups (SSH Port 22 and TCP Port 5000), systemd Docker service, and remote verification.

🌐

Practical 4: Google Cloud Platform

Provisioned on Google Compute Engine VM, protected with VPC ingress firewall rules (allow-ml-app-5000), and containerized restart policies.
